# Contributing / 贡献指南

## English

Use [GitHub Issues](https://github.com/zyz292/figurine-face-refinement/issues) for bug reports and suggestions. For a bug, include the skill version or commit, Blender version if relevant, the steps to reproduce it, and the expected and actual results. Use a small synthetic mesh or a sample you have permission to share.

For a pull request, explain the problem, the change, and how you verified it. Run `python tests/check_project.py` from the repository root. If you change Blender tools, run the relevant Blender checks listed in the [README](README.en.md). For changes that affect sculpting or visual review, include matching before and after views if available. Keep both READMEs in sync when changing installation or usage.

Contribute only material you have the right to share under the project's [MIT license](LICENSE).

## 简体中文

欢迎在 [GitHub Issues](https://github.com/zyz292/figurine-face-refinement/issues) 报告问题或提建议。报告问题时请提供 skill 版本或提交编号、相关的 Blender 版本、复现步骤、预期结果和实际结果。优先使用小型测试网格，或提供你有权分享的样例。

提交 PR 时请写明问题、改动和验证方法。在仓库根目录运行 `python tests/check_project.py`。如果修改了 Blender 工具，请运行[中文 README](README.md)中对应的 Blender 检查。涉及修模或视觉验收的修改，有条件时请附同机位的前后对照图。修改安装或用法时，请同步中英文 README。

请只提交你有权按本项目 [MIT 许可证](LICENSE) 分享的内容。
