# 大肥鱼面雕复盘

这个角色有三个 Hi3D 来源，约 500 万面原模、由其重拓扑的约 20 万面版本，以及约 200 万面版本。后者的手是重要选用因素，实际面部精修基于这个版本。大目标是全彩小手办，这轮明确把打印准备和颜色留到后面，Hi3D 接手贴图。

| 迭代 | 当时观察到的现象 | 调整与判断依据 |
| --- | --- | --- |
| 底模与早期鼻眼 | 鼻尖从过尖变得太平，正面调过的眼睛从侧面看像两个塞入的蛋。 | 看角色预览确认身份和神态，看佩丽卡成品面雕及头件侧面理解体积。把鼻尖前伸和圆钝分开调，眼面纳入连续的脸皮。 |
| v3–v7 | 磨平眼睛后，刘海旁仍有凹陷，眼下转折和双眼凹凸也不一致。 | 扩大到完整的眼角与脸颊过渡，保护眉、鼻、嘴和发片。建立随头旋转的左右对应点，共用大形，分别接回原脸。 |
| v8–v10 | 明确的下眼线把眼睛固定得太狭长，斜角还暴露出两侧眼下最低点差异。 | 根据预览重新定标眼型，只留上缘辅助定位，让下眼面顺入脸颊，眼白和瞳孔交给贴图。 |
| v11–v13 | 细线能定位，但撑不起预览里浓厚的上睫毛。 | 用一条连续的浮雕覆盖上缘及两侧眼角，在中段到外段增宽，主睫根逐渐汇合再分尖。下方中央继续留白。 |
| v14–v15 | v14 上方小尖略内收，主尖仅抬高，用户读成“边角缩了”。伊冯的面雕说明了贴根、收尖的做法，新提供的脸片说明了角色睫尖向太阳穴展开的方向。 | v15 把水平外伸和上翘分开控制，短尖与主尖从厚根向外扇开。沿相同头部坐标量两侧主尖，增加约为上一版上睫线宽度的 11%。带发正面、斜侧和去遮挡双眼检视后，用户接受该面部。 |

迁移到下一张脸时，重新选择底模、建立脸部坐标、区分两眼是否有意不对称，再量参考的轮廓与比例。两枚尖、11% 和 200 万面都是本例记录。一次交付可以只处理鼻尖、一个眼角或一侧眨眼。若上一版已被接受，针对新增要求另存版本。
